# צ'אט עם Claude · עברית (RTL) 🗨️

ממשק צ'אט בעברית מלאה, מימין לשמאל, מול Claude — עם יכולת **להריץ פקודות ולערוך קבצים** בתיקיית העבודה שלך (בסגנון Claude Code).

מכיוון שזו אפליקציית ווב, ה-RTL עובד נטיבית בדפדפן: הטקסט העברי מיושר נכון, ובלוקי קוד/נתיבים/מספרים מוצגים אוטומטית משמאל לימין. הבעיה של הכיווניות בטרמינל פשוט לא קיימת כאן.

## מה יש בפנים
- **צ'אט עם streaming** — התשובות מופיעות מילה-מילה.
- **הרצת כלים** — `bash`, קריאת קובץ, כתיבת קובץ, עריכת קובץ, רשימת תיקייה. כל קריאה מוצגת ככרטיס שאפשר לפתוח ולראות קלט/פלט.
- **בחירת מודל** — Sonnet 4.6 / Opus 4.8 / Haiku 4.5.
- **RTL מלא** — עברית מימין לשמאל, קוד משמאל לימין.

## התקנה והרצה

1. התקן תלויות:
   ```bash
   npm install
   ```

2. צור קובץ `.env` (העתק מ-`.env.example`) ושים בו את מפתח ה-API שלך מ-https://console.anthropic.com/ :
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

3. הרץ:
   ```bash
   npm start
   ```

4. פתח בדפדפן: http://localhost:3000

## הגדרות (קובץ `.env`)
| משתנה | ברירת מחדל | תיאור |
|-------|-----------|-------|
| `ANTHROPIC_API_KEY` | — | **חובה.** מפתח ה-API שלך |
| `PORT` | `3000` | פורט השרת |
| `WORKDIR` | התיקייה הנוכחית | תיקיית העבודה שבה הכלים פועלים |
| `DEFAULT_MODEL` | `claude-sonnet-4-6` | מודל ברירת המחדל |

## ⚠️ אבטחה
הכלים (`bash` וכו') רצים **על המחשב שמריץ את השרת**, עם ההרשאות שלך. הרץ רק קלט שאתה סומך עליו, והעדף להריץ מקומית ולא לחשוף את השרת לאינטרנט. קריאות וכתיבות קבצים מוגבלות ל-`WORKDIR` (הגנה בסיסית מ-path traversal), אבל `bash` עצמו אינו מוגבל.

## איך זה בנוי
- `server.js` — שרת Express. מנהל את **לולאת ה-agent**: שולח ל-Anthropic API עם הגדרת הכלים, וכשה-Claude מבקש להריץ כלי — מריץ אותו, מחזיר את התוצאה, וממשיך עד שאין עוד קריאות. מזרים הכל ל-frontend דרך SSE.
- `public/` — ה-frontend (HTML/CSS/JS טהור, ללא תלויות). `dir="rtl"` ב-HTML + כללי `direction: ltr` לקוד.
