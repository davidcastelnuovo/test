# צ'אט עם Claude · עברית (RTL) 🗨️

ממשק צ'אט בעברית מלאה, מימין לשמאל, מול Claude — עם יכולת **להריץ פקודות ולערוך קבצים** בתיקיית העבודה שלך. בנוי על **Claude Agent SDK** (`@anthropic-ai/claude-agent-sdk`) — אותו מנוע שמריץ את Claude Code עצמו, כך שזו אותה חוויית agent, רק בממשק ווב בעברית.

מכיוון שזו אפליקציית ווב, ה-RTL עובד נטיבית בדפדפן: הטקסט העברי מיושר נכון, ובלוקי קוד/נתיבים/מספרים מוצגים אוטומטית משמאל לימין. הבעיה של הכיווניות בטרמינל פשוט לא קיימת כאן.

## מה יש בפנים
- **מנוע agent אמיתי** — Claude Agent SDK מנהל את לולאת הכלים, ההקשר והעריכות בדיוק כמו Claude Code.
- **צ'אט עם streaming** — התשובות מופיעות מילה-מילה.
- **כלים מובנים** — `Bash`, `Read`, `Write`, `Edit`, `Glob`, `Grep`. כל קריאה מוצגת ככרטיס שאפשר לפתוח ולראות קלט/פלט.
- **הצגת חשיבה (thinking)** — מה-Claude חושב מוצג בבלוק מתקפל נפרד.
- **כפתור עצירה** — באמצע ריצה כפתור "שלח" הופך ל"עצור" ומבטל את הריצה (abort).
- **היסטוריית שיחות** — סרגל צד עם כל השיחות הקודמות (נשמרות אוטומטית ע"י ה-SDK). לחיצה טוענת שיחה וממשיכה אותה; יש גם מחיקה.
- **הקשר בין סבבים** — דרך `session` של ה-SDK (resume), בלי לשלוח מחדש את כל ההיסטוריה.
- **צירוף קבצים** — כפתור 📎, הדבקה, או גרירה. תוכן הקובץ נכנס ל-prompt.
- **שינוי שם / מחיקה לשיחות** — בסרגל הצד.
- **diff בעריכות** — קריאת `Edit` מציגה הפרש צבעוני (אדום/ירוק).
- **מעקב עלויות** — תג עלות מצטברת לכל שיחה (מבוסס `total_cost_usd` מה-SDK).
- **בחירת מודל** — Sonnet 4.6 / Opus 4.8 / Haiku 4.5.
- **RTL מלא** — עברית מימין לשמאל, קוד משמאל לימין.

## התקנה והרצה

1. התקן תלויות:
   ```bash
   npm install
   ```

2. צור קובץ `.env` (העתק מ-`.env.example`) ושים בו את מפתח ה-API שלך מ-https://console.anthropic.com/ :
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

3. הרץ:
   ```bash
   npm start
   ```

4. פתח בדפדפן: http://localhost:3000

## הגדרות (קובץ `.env`)
| משתנה | ברירת מחדל | תיאור |
|-------|-----------|-------|
| `ANTHROPIC_API_KEY` | — | **חובה.** מפתח ה-API שלך |
| `PORT` | `3000` | פורט השרת |
| `WORKDIR` | התיקייה הנוכחית | תיקיית העבודה שבה הכלים פועלים |
| `DEFAULT_MODEL` | `claude-sonnet-4-6` | מודל ברירת המחדל |
| `AUTH_USER` / `AUTH_PASS` | — | הגנת סיסמה (HTTP Basic). **חובה לחשיפה ציבורית.** הגדר את שניהם כדי להפעיל. |

## 🚀 פריסה ל-Railway

האפליקציה צריכה תהליך מתמשך + דיסק (לא מתאים ל-Vercel serverless). הקבצים `Dockerfile` ו-`railway.json` כבר מוכנים.

1. דחוף את הקוד ל-GitHub.
2. ב-[railway.app](https://railway.app): **New Project → Deploy from GitHub repo** ובחר את הריפו (Railway יזהה את ה-`Dockerfile` אוטומטית).
3. ב-**Variables** הגדר:
   - `ANTHROPIC_API_KEY` — מפתח ה-API שלך.
   - `AUTH_USER` ו-`AUTH_PASS` — **חובה!** בלי זה כל מי שמגיע ל-URL יכול להריץ פקודות על השרת.
   - (אופציונלי) `DEFAULT_MODEL`.
4. תחת **Settings → Networking** לחץ **Generate Domain** כדי לקבל URL ציבורי.

> Railway מספק `PORT` אוטומטית והשרת מאזין לה. תיקיית העבודה לכלים היא `/workspace` (מוגדר ב-Dockerfile).

חלופות באותו עיקרון (תהליך מתמשך): Render, Fly.io, או כל VPS עם Docker (`docker build -t rtl-chat . && docker run -p 3000:3000 --env-file .env rtl-chat`).

## ⚠️ אבטחה
הכלים (`bash` וכו') רצים **על המחשב שמריץ את השרת**, עם ההרשאות שלך. הרץ רק קלט שאתה סומך עליו, והעדף להריץ מקומית ולא לחשוף את השרת לאינטרנט. קריאות וכתיבות קבצים מוגבלות ל-`WORKDIR` (הגנה בסיסית מ-path traversal), אבל `bash` עצמו אינו מוגבל.

## איך זה בנוי
- `server.js` — שרת Express. קורא ל-`query()` מ-Claude Agent SDK עם `canUseTool` (אישור אוטומטי) ו-`includePartialMessages: true`, ומזרים את האירועים (טקסט, חשיבה, קריאות כלים, תוצאות, סיום) ל-frontend דרך SSE. עצירה ע"י `abortController` שמופעל כשהלקוח מתנתק. ההיסטוריה נחשפת דרך `listSessions` / `getSessionMessages` / `deleteSession` של ה-SDK.
- `public/` — ה-frontend (HTML/CSS/JS טהור, ללא תלויות). `dir="rtl"` ב-HTML + כללי `direction: ltr` לקוד. שולח `prompt` + `sessionId` לכל סבב.

> הערה: כל שיחה חדשה מקבלת `sessionId` נפרד מה-SDK, וההיסטוריה מציגה את כולן.

> ה-SDK מביא איתו binary מובנה של Claude Code (אין צורך להתקין את ה-CLI בנפרד). דורש Node 18+.
