# צ'אט עם Claude · עברית (RTL) 🗨️

ממשק צ'אט בעברית מלאה, מימין לשמאל, מול Claude — עם יכולת **להריץ פקודות ולערוך קבצים** בתיקיית העבודה שלך. בנוי על **Claude Agent SDK** (`@anthropic-ai/claude-agent-sdk`) — אותו מנוע שמריץ את Claude Code עצמו, כך שזו אותה חוויית agent, רק בממשק ווב בעברית.

מכיוון שזו אפליקציית ווב, ה-RTL עובד נטיבית בדפדפן: הטקסט העברי מיושר נכון, ובלוקי קוד/נתיבים/מספרים מוצגים אוטומטית משמאל לימין. הבעיה של הכיווניות בטרמינל פשוט לא קיימת כאן.

## מה יש בפנים
- **מנוע agent אמיתי** — Claude Agent SDK מנהל את לולאת הכלים, ההקשר והעריכות בדיוק כמו Claude Code.
- **צ'אט עם streaming** — התשובות מופיעות מילה-מילה.
- **כלים מובנים** — `Bash`, `Read`, `Write`, `Edit`, `Glob`, `Grep`. כל קריאה מוצגת ככרטיס שאפשר לפתוח ולראות קלט/פלט.
- **הקשר בין סבבים** — דרך `session` של ה-SDK (resume), בלי לשלוח מחדש את כל ההיסטוריה.
- **בחירת מודל** — Sonnet 4.6 / Opus 4.8 / Haiku 4.5.
- **RTL מלא** — עברית מימין לשמאל, קוד משמאל לימין.

## התקנה והרצה

1. התקן תלויות:
   ```bash
   npm install
   ```

2. צור קובץ `.env` (העתק מ-`.env.example`) ושים בו את מפתח ה-API שלך מ-https://console.anthropic.com/ :
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

3. הרץ:
   ```bash
   npm start
   ```

4. פתח בדפדפן: http://localhost:3000

## הגדרות (קובץ `.env`)
| משתנה | ברירת מחדל | תיאור |
|-------|-----------|-------|
| `ANTHROPIC_API_KEY` | — | **חובה.** מפתח ה-API שלך |
| `PORT` | `3000` | פורט השרת |
| `WORKDIR` | התיקייה הנוכחית | תיקיית העבודה שבה הכלים פועלים |
| `DEFAULT_MODEL` | `claude-sonnet-4-6` | מודל ברירת המחדל |

## ⚠️ אבטחה
הכלים (`bash` וכו') רצים **על המחשב שמריץ את השרת**, עם ההרשאות שלך. הרץ רק קלט שאתה סומך עליו, והעדף להריץ מקומית ולא לחשוף את השרת לאינטרנט. קריאות וכתיבות קבצים מוגבלות ל-`WORKDIR` (הגנה בסיסית מ-path traversal), אבל `bash` עצמו אינו מוגבל.

## איך זה בנוי
- `server.js` — שרת Express. קורא ל-`query()` מ-Claude Agent SDK עם `permissionMode: 'bypassPermissions'` ו-`includePartialMessages: true`, ומזרים את האירועים (טקסט, קריאות כלים, תוצאות, סיום) ל-frontend דרך SSE. ה-SDK מנהל לבד את לולאת הכלים ואת ההקשר.
- `public/` — ה-frontend (HTML/CSS/JS טהור, ללא תלויות). `dir="rtl"` ב-HTML + כללי `direction: ltr` לקוד. שולח `prompt` + `sessionId` לכל סבב.

> ה-SDK מביא איתו binary מובנה של Claude Code (אין צורך להתקין את ה-CLI בנפרד). דורש Node 18+.
